1. Executive Summary
Candy Station is an e-commerce website for a premium cotton candy brand based in Lahore, Pakistan. Customers can browse a flavor catalog with cinematic, GSAP-animated product showcases, add products to a cart, check out via Cash on Delivery (COD) or store pickup, create accounts, and track order status in real time. Store staff manage products, categories, orders, customers, and settings through a password-protected admin panel.
Architecture: a Next.js (App Router, TypeScript) frontend with GSAP (ScrollTrigger) animations consumes a .NET Core (ASP.NET Core) Web API backed by Microsoft SQL Server. The existing static HTML/CSS/JS prototype (in this repository) is the validated reference for all business logic, copy, and data; this PRD formalizes the production rebuild.
This PRD gives a receiving AI agent everything needed to build the production system.

3. Goals & Success Metrics
3.1 Product goals
1. Let customers discover, buy, and track cotton candy products in under 3 minutes.
2. Make the catalog feel premium: GSAP-animated product hero, scroll reveals, and a flavor carousel like the Fizzi benchmark.
3. Let store staff manage the entire catalog and order pipeline without touching code (admin panel served by the same Next.js app or a separate route group).
4. Production-grade data: MS SQL Server persistence, REST API, secure auth — replacing the localStorage simulation 1:1.

? Checkout completion rate ? 40% of cart sessions (analytics once live)
? Median order placement time ? 3 minutes

7. Data Model — Microsoft SQL Server
The prototype's JSON schema maps 1:1 to the tables below. The API (EF Core) owns all persistence; the frontend never touches SQL.
7.1 Entity-Relationship overview
Categories 1—? Products 1—? ProductVariants · Customers 1—? Orders 1—? OrderItems · Orders 1—? OrderTimeline · Orders ?—1 DeliveryZones · AdminUsers · Settings (single-row).
7.2 T-SQL DDL (target schema)
CREATE TABLE Categories (
  Id            INT IDENTITY(1,1) PRIMARY KEY,
  Name          NVARCHAR(100)  NOT NULL,
  Description   NVARCHAR(500)  NULL,
  DisplayOrder  INT            NOT NULL DEFAULT 0,
  Status        NVARCHAR(20)   NOT NULL DEFAULT 'active' CHECK (Status IN ('active','inactive')),
  CreatedAt     DATETIME2      NOT NULL DEFAULT SYSUTCDATETIME(),
  UpdatedAt     DATETIME2      NOT NULL DEFAULT SYSUTCDATETIME()
);
 
CREATE TABLE Products (
  Id             INT IDENTITY(1,1) PRIMARY KEY,
  CategoryId     INT            NOT NULL REFERENCES Categories(Id),
  Name           NVARCHAR(150)  NOT NULL,
  Description    NVARCHAR(2000) NULL,
  Ingredients    NVARCHAR(1000) NULL,
  ServingSize    NVARCHAR(50)   NULL,
  Calories       INT            NULL,
  Fat            NVARCHAR(50)   NULL,
  Carbs          NVARCHAR(50)   NULL,
  Protein        NVARCHAR(50)   NULL,
  Price          DECIMAL(10,2)  NOT NULL,           -- base price (first variant)
  CompareAtPrice DECIMAL(10,2)  NULL,
  CostPrice      DECIMAL(10,2)  NULL,               -- internal, admin only
  Stock          INT            NOT NULL DEFAULT 0,
  Sku            NVARCHAR(50)   NOT NULL UNIQUE,
  Status         NVARCHAR(20)   NOT NULL DEFAULT 'active' CHECK (Status IN ('active','inactive')),
  Weight         NVARCHAR(20)   NULL,
  FlavorTags     NVARCHAR(500)  NULL,               -- comma-separated
  CandyColor     NVARCHAR(9)    NOT NULL DEFAULT '#F90264',
  Rating         DECIMAL(2,1)   NOT NULL DEFAULT 0,
  ReviewCount    INT            NOT NULL DEFAULT 0,
  CreatedAt      DATETIME2      NOT NULL DEFAULT SYSUTCDATETIME(),
  UpdatedAt      DATETIME2      NOT NULL DEFAULT SYSUTCDATETIME()
);
 
CREATE TABLE ProductVariants (
  Id        INT IDENTITY(1,1) PRIMARY KEY,
  ProductId INT            NOT NULL REFERENCES Products(Id) ON DELETE CASCADE,
  Name      NVARCHAR(100)  NOT NULL,
  Price     DECIMAL(10,2)  NOT NULL,
  SortOrder INT            NOT NULL DEFAULT 0
);
 
CREATE TABLE Customers (
  Id          INT IDENTITY(1,1) PRIMARY KEY,
  Name        NVARCHAR(150) NOT NULL,
  Email       NVARCHAR(150) NOT NULL UNIQUE,
  Phone       NVARCHAR(30)  NULL,
  PasswordHash NVARCHAR(256) NOT NULL,               -- PBKDF2/BCrypt, never plain text
  JoinedDate  DATETIME2     NOT NULL DEFAULT SYSUTCDATETIME(),
  OrdersCount INT           NOT NULL DEFAULT 0,
  TotalSpent  DECIMAL(10,2) NOT NULL DEFAULT 0
);
 
CREATE TABLE CustomerAddresses (
  Id          INT IDENTITY(1,1) PRIMARY KEY,
  CustomerId  INT           NOT NULL REFERENCES Customers(Id) ON DELETE CASCADE,
  Label       NVARCHAR(50)  NULL,
  Name        NVARCHAR(150) NOT NULL,
  Phone       NVARCHAR(30)  NOT NULL,
  Address1    NVARCHAR(200) NOT NULL,
  Address2    NVARCHAR(200) NULL,
  City        NVARCHAR(100) NOT NULL,
  State       NVARCHAR(100) NOT NULL,
  PostalCode  NVARCHAR(20)  NOT NULL,
  Country     NVARCHAR(100) NOT NULL DEFAULT 'Pakistan'
);
 
CREATE TABLE DeliveryZones (
  Id          INT IDENTITY(1,1) PRIMARY KEY,
  Name        NVARCHAR(50)   NOT NULL,
  Description NVARCHAR(200)  NULL,
  Cost        DECIMAL(10,2)  NOT NULL,
  Enabled     BIT            NOT NULL DEFAULT 1
);
 
CREATE TABLE Orders (
  Id            INT IDENTITY(1,1) PRIMARY KEY,
  OrderNumber   NVARCHAR(20)   NOT NULL UNIQUE,     -- 'ORD-2026-0001'
  CustomerId    INT            NULL REFERENCES Customers(Id),  -- NULL = guest
  CustomerName  NVARCHAR(150)  NOT NULL,
  CustomerEmail NVARCHAR(150)  NOT NULL,
  CustomerPhone NVARCHAR(30)   NOT NULL,
  Subtotal      DECIMAL(10,2)  NOT NULL,
  Shipping      DECIMAL(10,2)  NOT NULL DEFAULT 0,
  Total         DECIMAL(10,2)  NOT NULL,
  PaymentMethod NVARCHAR(20)   NOT NULL DEFAULT 'COD',
  DeliveryMethod NVARCHAR(20)  NOT NULL CHECK (DeliveryMethod IN ('delivery','pickup')),
  DeliveryZoneId INT           NULL REFERENCES DeliveryZones(Id),
  ShippingAddressId INT        NULL REFERENCES CustomerAddresses(Id),
  Status        NVARCHAR(20)   NOT NULL DEFAULT 'pending'
                CHECK (Status IN ('pending','confirmed','preparing','out_for_delivery','delivered','cancelled')),
  Notes         NVARCHAR(1000) NULL,
  PlacedAt      DATETIME2      NOT NULL DEFAULT SYSUTCDATETIME()
);
 
CREATE TABLE OrderItems (
  Id        INT IDENTITY(1,1) PRIMARY KEY,
  OrderId   INT            NOT NULL REFERENCES Orders(Id) ON DELETE CASCADE,
  ProductId INT            NOT NULL REFERENCES Products(Id),
  ProductName NVARCHAR(150) NOT NULL,               -- snapshot
  VariantName  NVARCHAR(100) NOT NULL,              -- snapshot
  UnitPrice DECIMAL(10,2)  NOT NULL,
  Quantity  INT            NOT NULL,
  LineTotal DECIMAL(10,2)  NOT NULL
);
 
CREATE TABLE OrderTimeline (
  Id      INT IDENTITY(1,1) PRIMARY KEY,
  OrderId INT           NOT NULL REFERENCES Orders(Id) ON DELETE CASCADE,
  Status  NVARCHAR(20)  NOT NULL,
  ChangedAt DATETIME2   NOT NULL DEFAULT SYSUTCDATETIME()
);
 
CREATE TABLE AdminUsers (
  Id           INT IDENTITY(1,1) PRIMARY KEY,
  Username     NVARCHAR(50)  NOT NULL UNIQUE,
  PasswordHash NVARCHAR(256) NOT NULL,
  DisplayName  NVARCHAR(100) NULL,
  IsActive     BIT           NOT NULL DEFAULT 1
);
 
CREATE TABLE Settings (
  Id              INT IDENTITY(1,1) PRIMARY KEY,
  StoreName       NVARCHAR(150) NOT NULL DEFAULT 'Candy Station',
  StoreAddress    NVARCHAR(300) NULL,
  StorePhone      NVARCHAR(30)  NULL,
  StoreEmail      NVARCHAR(150) NULL,
  StoreHours      NVARCHAR(100) NULL,
  Currency        NVARCHAR(10)  NOT NULL DEFAULT 'PKR',
  PickupAddress   NVARCHAR(300) NULL,
  PickupHours     NVARCHAR(100) NULL,
  CodEnabled      BIT           NOT NULL DEFAULT 1,
  CodMinOrder     DECIMAL(10,2) NOT NULL DEFAULT 0,
  CodMaxOrder     DECIMAL(10,2) NOT NULL DEFAULT 10000,

8. Technical Architecture
8.1 Frontend — Next.js + GSAP
? Next.js 14+ (App Router), TypeScript. Server Components for content pages; client components isolated to interactive islands (carousel, cart, checkout, admin).
? GSAP 3 with ScrollTrigger (and useGSAP hook for React 18 StrictMode safety). Optional: Lenis for buttery smooth scroll (respect prefers-reduced-motion).
? Data fetching: Server Components call the .NET API (SSR/ISR for catalog pages, e.g. revalidate = 300); client mutations (cart/checkout/auth) call the API via a typed fetch client.
? State: cart in a lightweight context + localStorage persistence; auth token in httpOnly cookie (server middleware validates).
? Styling: CSS Modules or Tailwind with the design tokens from §10. No gradients.
? Product art: SVG cotton candy rendered from CandyColor (ported from the prototype's generateScoopSVG), animated by GSAP.
8.2 Backend — ASP.NET Core Web API
? .NET 8 LTS, minimal APIs or controllers; EF Core 8 with SQL Server provider; migrations checked into /backend/Migrations.
? Auth: JWT bearer (customer + admin role claims); PasswordHasher (PBKDF2, 100k+ iterations); admin endpoints require [Authorize(Roles = "Admin")].
? Contracts: DTOs for all entities (never expose EF entities directly); FluentValidation for inputs; global exception middleware returning RFC 7807 problem details; CORS allowlist for the Vercel origin; Swagger/OpenAPI enabled (dev).
? Services: ProductService, OrderService (order number generation ORD-{year}-{seq:0000}, totals, timeline, stock decrement), AuthService, StatsService.
